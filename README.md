# 三省街机

一个像素风的网页游戏大厅。在浏览器里选一款游戏就能开玩，支持电脑键盘和手机触控。

[进入游戏大厅](https://sansheng-arcade.vercel.app/)

## 坦克大战 2D

大厅上架的第一款游戏。守住基地，消灭本关的敌方坦克即可过关。内置 35 个经典关卡，支持单人闯关和双人同键盘合作。[直接开玩](https://sansheng-arcade.vercel.app/tank2d.html)

- 在标题画面按上下方向键切换人数，按回车开始。游戏中按回车暂停或继续，按 `M` 切换静音。
- 每关结算时自动保存下一关的起点、人数、分数、剩余生命和升级等级。重新打开同一浏览器，在标题页选择「继续第 N 关」。经典与自定义地图分别存档，开始新游戏会替换该地图模式的旧记录。
- 玩家一使用 `WASD` 移动，空格或 `J` 开火。单人模式也可以用方向键移动。
- 玩家二使用方向键移动，小键盘 `0`、句号键或斜杠键开火。
- 手机上用左拇指拖动摇杆，滑向上下左右即可移动或转向，松手回中。右手可同时按住发射按钮连续开火。

## 坦克大战 3D

[直接开玩 3D 版](https://sansheng-arcade.vercel.app/tanke3d.html)

在立体战场中保卫基地，支持单人和同屏双人。游戏按键与 2D 版相近，按 `Q` / `E` 旋转视角，`V` 切换俯视或斜视，`R` 复位。手机上用左侧摇杆移动，右手按住发射，拖动战场可调整视角。此版本接自 Jarvis Uni，使用 Three.js 和 WebGL 渲染。[原版页面](https://www.jarvisuni.com/game/tanke3d.html)

每关结算后会在本机自动保存下一关的起点，包括单人或双人模式、各玩家的生命、分数和升级等级。在同一浏览器选择相同地图集，点「继续第 N 关」即可续玩。开始新游戏会替换该地图集的存档，通关后清除；2D 和 3D 的进度独立保存。

## 本地运行

项目使用 HTML、CSS 和原生 JavaScript，《坦克大战 2D》使用 Canvas 2D，《坦克大战 3D》的脚本、样式和渲染库随站点提供。装有 Python 3 时，在仓库根目录运行以下命令即可预览。

```sh
python3 -m http.server 8715 --bind 127.0.0.1
```

在浏览器打开[本地游戏大厅](http://127.0.0.1:8715/)。
